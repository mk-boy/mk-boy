## Привет, я Миша 👋

PHP Backend-разработчик.

Проектирую REST API с понятным контрактом, на который удобно опираться фронтенду и внешним интеграциям. Автоматизирую бизнес-процессы: превращаю ручной сбор данных, сверки и отчёты в сервисы, Telegram-ботов и интеграции.

Люблю находить узкие места: разбираю планы выполнения медленных SQL-запросов и ускоряю тяжёлые отчёты в PostgreSQL и MySQL. Не боюсь legacy-кода и умею переводить его на современный PHP 8.x со строгой типизацией и модульной архитектурой.

Веду задачи полным циклом, от проектирования до запуска и поддержки.
